# Kanko — ニッポン観光ランキング

みんなで登録・投票してつくる、日本の観光資源ランキングのランディングページです。

## 機能

- **都道府県No.1 全国ランキング**：各都道府県で最もいいねを集めた名所を全国で順位付け
- **都道府県別ランキング**：地方 → 都道府県を選んで、名所をいいね順に表示
- **カテゴリ絞り込み**：自然・子ども/家族・デート・歴史/文化・絶景・温泉・グルメ・アクティビティ
- **名所の登録**：誰でも名所を登録でき、自分の登録は削除可能
- **いいね投票**：1人1回、再度押すと取り消し
- レスポンシブ対応（PC / タブレット / スマホ）

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | ページ本体 |
| `style.css` | デザイン・レスポンシブ |
| `app.js` | ランキング・登録・絞り込みのロジック |
| `seed.js` | サンプル名所データ（47都道府県 × 10件） |

## 使い方

静的ファイルのみで動作します。任意のWebサーバー（GitHub Pages など）に配置してください。

## 注意

- 登録内容といいねは閲覧者のブラウザ（localStorage）に保存されます。利用者間では共有されません。
- 初期のいいね数はサンプル値です。
